01 — The Idea
Medium’s editor doesn’t speak Markdown. Every article I wrote lost its headings and code blocks on the way in.
02 — The Experiment
A single-file web app with a live Medium-style preview and a clipboard payload the Medium editor accepts as rich text.
  1. 01
    Markdown and HTML modes, each with its own autosaved draft.
  2. 02
    Serif preview with pull quotes and · · · dividers.
  3. 03
    Pasted HTML is sanitised — no javascript: or data: links survive.
  4. 04
    Word count, read time, and ⌘⇧C to copy for Medium.
03 — The Technology
No backend. marked for GFM, the Clipboard API for rich text, localStorage for drafts.

  2. 02Parsemarked · GFM
  3. 03SanitiseSafe tags only
  4. 04Copytext/html clipboard
